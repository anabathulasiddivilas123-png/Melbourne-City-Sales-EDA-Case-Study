# 🏙️ Melbourne City Sales - EDA Case Study

## 📌 Overview
This project is a detailed Exploratory Data Analysis (EDA) on Melbourne city sales data. The goal was to analyze sales patterns, customer behavior, and identify key factors affecting property/sales performance.

This case study was done as part of my learning journey at **Innomatics Research Labs, Dilsukhnagar**.

## 🎯 Objectives
- Clean and preprocess the raw sales data
- Analyze sales trends by region, time, and property type
- Identify top-performing areas and price patterns
- Visualize insights for business decisions

## 🛠️ Tech Stack
- **Python**
- **Pandas & NumPy** - Data Manipulation
- **Matplotlib & Seaborn** - Data Visualization
- **Jupyter Notebook**

## 📊 Key Insights Explored
1.  **Sales Trend Analysis** - Monthly & Yearly growth
2.  **Price vs Location** - Which suburbs have high demand
3.  **Property Type Analysis** - House, Unit, Townhouse performance
4.  **Correlation Study** - Factors affecting sales price

## 📁 Repository Structure
- `Data/` - Raw dataset
- `Notebook/` - Jupyter Notebook with complete EDA

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas matplotlib seaborn`
3. Open the Jupyter Notebook
