# 🏙️ Melbourne City Property Sales - EDA Case Study

## 📌 Overview
This project is a detailed Exploratory Data Analysis (EDA) on Melbourne City property sales data. The analysis aims to uncover sales trends, pricing patterns, and key factors influencing the real estate market.

This case study was completed as part of my learning journey at **Innomatics Research Labs, Dilsukhnagar**.

## 🎯 Objectives
- Data Cleaning & Preprocessing
- Analyze sales trends by Suburb, Property Type & Time
- Identify price drivers and correlation between features
- Visualize insights for business decision making

## 🛠️ Tech Stack
- **Python, Pandas, NumPy**
- **Matplotlib, Seaborn** for Visualization
- **Jupyter Notebook**

## 📊 Key Insights
- Identified top-performing suburbs in Melbourne
- Analyzed price distribution based on rooms, distance & property type
- Explored seasonal sales trends

## 📁 Files
- `Property sales Melbourne City.ipynb` - Complete EDA Notebook
- `Property Sales of Melbourne City.csv` - Dataset
